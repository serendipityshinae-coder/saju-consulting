# 사주 엔진 교차 검증

## 자동 테스트

- `npm test` — 절기·시진·입춘 경계 및 `reference-saju.json` 케이스
- 엔진 결과는 `lunar-javascript` EightChar(표준시·입춘·자정 일주)와 대조

## 외부 만세력 수동 검증

다른 만세력과 비교할 때 아래 **계산 기준**이 동일한지 먼저 확인합니다.

| 항목 | 본 서비스 MVP |
|------|----------------|
| 연주 | 입춘 절입 시각 |
| 월주 | 12절 절입 시각 |
| 일주 | JDN 60갑자 (자정 일 변경) |
| 시주 | 2시간 시진, 23시 이후 시두는 익일 일간 |
| 시간 | 한국 표준시 (진태양시 미적용) |
| 음력 | korean-lunar-calendar (윤달 포함) |

기준이 다르면 팔자가 달라질 수 있습니다. 차이가 나면 기준을 기록한 뒤 `tests/reference-saju.json`에 케이스를 추가하세요.
